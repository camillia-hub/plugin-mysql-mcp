# MySQL MCP

Queries a MySQL or MariaDB database. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/mysql-mcp

Installs from the Camillia hub as `mysql-mcp-92bf86`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
